# Deployment Guide

Deploy AI agents to GCP and connect them to Twilio.

## Deployment methods

- **[Agent Platform Runtime](./agent_platform/)** (Available Now) — deploy your
  agent to GCP's managed Agent Platform Runtime (Reasoning Engine) and connect it
  to Twilio.
- **[CX Agent Studio](./cx_agent_studio/)** (Available Now) — connect Twilio to an
  agent built in CX Agent Studio (Customer Engagement Suite).
- **App Engine** (Coming Soon)
